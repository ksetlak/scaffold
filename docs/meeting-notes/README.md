# Meeting Notes

Minutes of meetings and similar sources. This folder is supporting context, not a source of truth for scope, architecture, or implementation. Something said in a meeting is not an accepted decision until it is recorded in an ADR, a PRD, or a backlog item.

File naming convention: Name files `YYYY-MM-DD_short-slug.md` (`short-slug` mostly being just the name of the meeting).

## For AI agents

Do not read this folder by default. Read a note only when the task or the operator points you to it. Treat what you find as unverified: transcripts are often auto-generated, noisy, and incomplete. Confirm anything that affects scope, architecture, or implementation against accepted ADRs, PRDs, and the backlog, or with the operator, before acting on it.
