# Meeting Notes

Minutes of meetings and similar sources. Not a source of truth for scope, architecture, or implementation - just additional info.

File naming convention: Name files `YYYY-MM-DD_short-slug.md` (`short-slug` mostly being just the name of the meeting).

## For AI agents

Ignore this folder roughly 90% of the time. Meeting notes are often auto-transcribed, noisy, and unreliable. See root `README.md` for source hierarchy and the role of each part of the repository.
