# Product Requirements Documents

Each PRD captures product goals, scope, requirements, acceptance criteria, and open questions for a feature or release.

## Status convention

| Status | Meaning |
|--------|---------|
| `DRAFT` | In progress — not final scope yet |
| `IN_REVIEW` | Stakeholders reviewing — scope may still change |
| `APPROVED` | Binding product definition for implementation and backlog work |
| `SHIPPED` | Delivered — kept for history and traceability |

When a newer PRD supersedes an older one, update the older PRD's status and this index.

## Template
